# Test plan

One suite per notebook, with the same case IDs, in the same order, in both implementations; each case is a markdown
cell `## ID · title` followed by one code cell. `support.py` holds the shared helpers. TypeScript's plan lists only its
differences.

| Notebook | Suite | Cases | Covers |
|---|---|---|---|
| `01_Types.ipynb` | TYP | 14 | The store of a session: the schemas a store registers and those they refer to, Python's syntax trees, and the output, whose singleton holds the module, read through the visitor protocols with a module and without, its extent reached from the output; `Dataclass`'s candidates, one per value of `frozen`, for each object schema it renders, and none for those it does not (an inline object, another format's native, a list bounded by a term, a named native, a named union, lists of another format's native nested nine deep, a dict keyed by a schema, parameters, adjacencies), `missing` before and after a run, lists of a class nested nine deep rendered, a named native's field naming its alias; steps taken by the caller and by a policy, the module printed exactly (imports once, classes in name order, `eq=False`, `frozen=True` and both, a docstring with escapes, `pass`, natives, named schemas and lists), the trace, each step linking the class it wrote, and reading back the schema, by role, named by path in a written trace, `generate` with its default policy and another, a valid tree; `Schema` reading classes back (references filled when read, lists, `eq=False`, docstrings in double, single and triple quotes with escapes, annotations without `\| None`, fields with other values, a first statement that is not a docstring, undecorated and otherwise decorated classes not read, a store given), and the annotations it refuses, by field (`dict` without two parameters, `set`, attributes, unions of types, other operators); both round trips, given the same decisions; regenerating after the schemas change: decisions taken again by key (the schema's name), the new schema left to ask, the gone one reported as an orphan, the diff of the two generations, `generate` given earlier steps; dicts keyed by natives, nested lists and keyword fields, generated exactly, read back and generated again; names Python cannot spell written as the schemas have them, reported by path, and refused when the source is taken; relations as entry classes and adjacencies as fields holding entries on both ends (links typed by their declarers, two declarers, properties, two uniques, a description, a self-relation's links in metadata), both round trips, one function reading proxies and generated classes alike, what renders no entry class (a link nobody declares, parameters, a property of an unrendered type, an unnamed relation), and reading back (an unknown relation refused, a self-relation without its link refused, a relation the store holds with its link given and without, a link of another annotation); unions and intersections as value classes of a dataclass field per branch or part, both round trips, one function reading proxies and generated classes alike, frozen by the decision, what renders no class (no branches, parameters, a branch of an inline type), a name neither a class of the module nor a schema of the store refused; flat unions as type aliases and flat intersections as classes of their parts' properties (`PARTS`: a named part and an inline one), branch names and a description in `Annotated` metadata and a plain alias without, both round trips, one function reading proxies and generated classes alike, what renders neither (a flat intersection's part whose properties do not render, inline or named); nothing lost: a singleton and the descriptions of properties, adjacencies, a relation's property, a branch, a flat union's branch, a flat intersection's part and its inline part's property written exactly and read back both ways, a field without metadata, and natives with a width that is a term or with parameters left without a class; named natives and lists as type aliases (a described native, a plain one, a list of a class, of a named native, a dict keyed by one, a flat union of named natives) written exactly, each step writing an alias, read back both ways, an alias no class names read by its own step, what has no alias (another format's native, a list bounded by a term, a list of an inline object) in `missing`, and the aliases reading refuses (of a class, a list holding itself); widths in bits and bytes, extents with and without a maximum, natives' own descriptions, `python3` tokens, inline and in aliases, and a flat union's annotated branch named after its type, written exactly as `Annotated` metadata and read back both ways, and a `python3` token proxies have no host type for left without an alias |
| `02_Skill.ipynb` | SKL | 3 | The packaged copy of the skill is current; every complete program in the skill runs; every link in the agent guides resolves, anchors included |

Total: 17 cases, with the same IDs in the same order in both implementations.

## Not testable yet

What is not rendered yet: parametric schemas, other formats' natives, widths and extents that are terms (see the design's open
questions); incremental rebuilds (mbse-patterns' plan).
